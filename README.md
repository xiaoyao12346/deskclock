# DeskClock 2.0 — 基于 STM32F411 + LVGL 的桌面智能时钟

> 一块 256×64 的灰度 OLED，一块 STM32F411，加上 LVGL —— 做一个能看时间、看天气、看室内环境、还能当番茄钟的桌面小屏。

一个从驱动、UI、联网到低功耗全流程自己写完的嵌入式练手项目：硬件驱动自己写，界面用 LVGL 手写布局，天气走 ESP8266 的 AT 指令取心知天气数据，配网靠设备自己开热点 + 网页表单，不装 App、不插串口。

---

## ✨ 功能特性

### 五个主页面

| 页面 | 内容 |
|---|---|
| **时钟** | RTC 走时、日期、星期；联网时通过 SNTP 自动对时 |
| **室外天气** | 心知天气 3 日预报，5 个子页：3 日概览 / 今天 / 明天 / 后天 / 风向湿度对比 |
| **室内环境** | AHT20 温湿度 + BMP280 气压，6 个子页：概览 / 温度 / 湿度 / 气压 / 趋势预测 / 舒适度评估 |
| **番茄钟** | 3 张卡片：倒计时、番茄钟、闹钟；支持编辑时长、振动提醒 |
| **设置** | 时间、番茄钟时长、振动开关、WiFi 配网 |

### 其他亮点

- **网页配网，零依赖**：设备开热点 `Clock-Setup`，手机连上后浏览器打开 `192.168.4.1`，填 WiFi 名称/密码/城市即可。不需要 App，也不需要串口助手。
- **掉电保存**：天气数据与 WiFi 配置写入 Flash Sector 7，断电重启不用重新配网。
- **断网可用**：拿不到网络时继续显示上一次缓存的天气，不会白屏。
- **低功耗**：空闲 60 秒自动进 Stop 模式，支持 RTC 定时、按键、以及 MPU6050 运动检测三种唤醒源。
- **全程裸机**：没有 RTOS，用「超级循环 + 事件队列 + 状态机」把 UI、联网、传感器、低功耗组织起来。

## 🔧 硬件

| 部件 | 型号 / 说明 |
|---|---|
| 主控 | STM32F411RET6（Cortex-M4F，100 MHz，512 KB Flash / 128 KB RAM） |
| 显示屏 | SSD1322，256×64，**4-bit 灰度（16 级）**，硬件 SPI1 + DMA2 刷屏 |
| 温湿度 | AHT20（I2C） |
| 气压 | BMP280（I2C） |
| 姿态 | MPU6050（I2C，用其中断做运动唤醒） |
| 联网 | ESP8266，AT 固件，走 USART1 |
| 按键 | 3 个（PA0 / PB12 / PB13），均为下拉输入 + 外部上拉 |
| 时钟源 | 8 MHz HSE 主时钟，32.768 kHz LSE 供 RTC |

### 引脚分配（显示部分）

| 引脚 | 功能 |
|---|---|
| PA5 | SPI1_SCK → OLED SCL |
| PA7 | SPI1_MOSI → OLED SDA |
| PA2 | OLED RES |
| PA3 | OLED DC |
| PA4 | OLED CS |

> 注意：SPI1 与 DMA2 是在 `CORE/ssd1322.c` 里手工初始化的，`deskclock2.0.ioc` 中并未包含这部分配置，重新用 CubeMX 生成代码时不要覆盖掉它。

## 🚀 编译与烧录

**环境**：Keil MDK-ARM 5，ARM Compiler V5.06 update 7

1. 用 Keil 打开 `MDK-ARM/deskclock2.0.uvprojx`
2. 确认器件为 `STM32F411RETx`
3. `Build`（F7）→ 用 ST-Link / DAP-Link 下载到板子

编译产物约占用 **Code ≈ 192 KB / RO-data ≈ 86 KB / ZI ≈ 100 KB**，F411 的 512 KB Flash 有充足余量。

## 🔑 配置天气 API Key（必做）

天气功能需要自己的心知天气密钥，仓库里是占位符：

```c
// CORE/my_wifi.c  约第 528 行
sprintf(Request, "GET /v3/weather/daily.json?key=YOUR_API_KEY&location=%s...", ...);
```

1. 到 [心知天气](https://www.seniverse.com/) 注册账号，获取免费版 API Key
2. 把 `YOUR_API_KEY` 替换成你的 Key
3. 重新编译烧录

> 免费版有调用频率与天数限制，个人使用足够。请不要把真实 Key 提交到仓库。

## 📶 WiFi 配网步骤

1. 设备进入 **设置 → WiFi 配网**，屏幕会显示热点名与访问地址
2. 手机连接热点 `Clock-Setup`（无密码）
3. 浏览器打开 `192.168.4.1`
4. 填写：WiFi 名称、WiFi 密码、城市（用拼音，如 `beijing`）
5. 提交后配置写入 Flash，设备自动重启并联网

联网成功后会自动：拉取 3 日天气 → SNTP 校准时间 → 之后定时刷新。网络异常时每 5 秒重试。

## 🧠 实现要点

- **4bpp 灰度刷屏**：SSD1322 每个字节存两个像素。UI 以 16bpp 渲染后，在 `lv_port_disp.c` 里量化成 4-bit 灰度写入帧缓冲（`64 × 128 = 8 KB`），再按行用 DMA2 分块搬运，避免整屏刷新卡顿。
- **事件驱动 UI**：传感器采集、联网任务不直接画界面，只往事件队列里投事件；主循环统一消费并更新 LVGL 控件，避免跨模块直接操作控件。
- **AT 指令状态机**：ESP8266 的联网、取天气、SNTP、AP 配网全部拆成显式状态（发送 → 等待应答 → 超时重试），带 5 秒/10 秒/15 秒分级超时，任何一个环节失败都能回到错误态重连而不死等。
- **Flash 分扇区管理**：天气数据与 WiFi 配置同处 Sector 7，因为擦除按整扇区进行，所以两份数据必须一起读、一起写，代码里用地址偏移 + magic 校验保证一致性。
- **低功耗唤醒**：进 Stop 前把按键脚切成 EXTI 下降沿唤醒，退出后重新初始化外设并恢复界面。

## ⚠️ 已知限制

- 天气功能依赖心知天气的免费额度，额度用尽后会一直显示缓存数据
- RTC 若没有纽扣电池备份，完全断电后会丢失时间
- 界面布局是按 256×64 定死的，换分辨率需要改 `lv_port_disp.c` 和大量布局常量
- `deskclock2.0.ioc` 与工程实际外设不完全同步（SPI1/DMA 为手写初始化）
